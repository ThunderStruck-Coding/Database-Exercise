## 📄 Key Topics & Research

### 🔒 Security Vulnerabilities in Flask Web Applications
[View PDF Document](./security%20vulnerabilities%20in%20Flask%20web%20applications.pdf)

This paper details common web application security risks and mitigation techniques within the Python Flask framework, including:
* **Common Vulnerabilities:** In-depth analysis of SQL Injection (SQLi), Cross-Site Scripting (XSS), and authentication bypass vectors.
* **Security Controls:** Implementation of secure session management, input sanitization, and password hashing.
* **Compliance & Data Privacy:** Application of GDPR principles and secure data storage practices.
